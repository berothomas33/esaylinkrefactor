## P3 — VendorApplication

The PAX SDK (commonutils, poslib, bizlib, bizentity) calls `BaseApplication.getAppContext()`, so
the PAX app must still be a `BaseApplication`. Each vendor provides
`com.emvenhance.vendor.VendorApplication` (PAX: `extends BaseApplication`; others:
`extends Application`); `EmvEnhanceApp extends VendorApplication`, logs with `android.util.Log`.
